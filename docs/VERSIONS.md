เลือกจาก [Releases](https://github.com/orchex006/agrimap-agent-skills/releases) ของแพ็กเกจ ไม่ถือว่าเลขใน working copy หรือ changelog แปลว่ารุ่นนั้นเผยแพร่แล้ว รุ่นเก่าที่ยังไม่มี tag/artifact ที่ตรวจสอบได้ต้องรายงานว่า unavailable ห้ามแทนด้วย latest โดยเงียบ ๆ

| สิ่งที่ต้องการ | วิธีเลือก |
| --- | --- |
| รุ่น stable ที่ระบุ | เลือก release/tag v<version> และ archive ของ host ที่ใช้ |
| ทดลอง preview | เลือก prerelease อย่างชัดเจน ไม่ใช้เป็น stable อัตโนมัติ |
| กลับรุ่นก่อน | ตรวจ compatibility และสำรอง installation/config ก่อนแทนที่ด้วยรุ่นที่ระบุ |
| ตรวจว่าได้รุ่นไหน | เปรียบเทียบ manifest ที่ติดตั้งกับ release.json แล้วเปิด session ใหม่ |

สำหรับรุ่นที่แจกด้วย runtime artifacts ให้ดาวน์โหลด archive .tgz ของ Codex, Claude หรือ Antigravity พร้อม release.json และ SHA256SUMS จาก release เดียวกัน ตรวจ SHA-256 ก่อนแตกลงโฟลเดอร์ว่าง เก็บ directory นี้ไว้ตลอดเวลาที่ host ใช้เป็น local source ไม่แตกทับ cache หรือ source ของโครงการ

จาก directory ที่แตกไฟล์ ใช้วิธี local package ของ host ตาม [คู่มือติดตั้ง](MAINTAINING.md#local-install) โดยไม่รัน npm run sync: runtime artifact สร้างเสร็จแล้ว ตรวจ help และ marketplace registration ก่อนเปลี่ยน source โดยเฉพาะกรณีชื่อ marketplace เดิมชี้ GitHub อยู่ ห้ามเปลี่ยน registration ของ plugin อื่นเพื่อ pin AGM

archive ของ Codex/Claude มี local marketplace และ plugin payload ของ host นั้น ส่วน Antigravity มี root plugin.json, package.json และ flat skills ไม่มี development workflow ใน payload ผล native installation ต้องตรวจบน host รุ่นที่ใช้จริง; การแตกไฟล์และตรวจ manifest ผ่านไม่ได้พิสูจน์ว่า host ติดตั้งสำเร็จ

Source code zip/tar ที่ GitHub สร้างอัตโนมัติและการ clone repository เป็น source distributions ไม่ใช่ runtime archive ที่แยกกฎผู้พัฒนาไว้ รุ่นเก่าก่อนมี runtime artifacts อาจต้องใช้วิธีติดตั้งที่รองรับของรุ่นนั้นและตรวจแหล่งที่มาเพิ่ม

การเลือกใช้รุ่นก่อนหมายถึงการแทน installation ที่เลือก ไม่รับประกันการติดตั้งหลายรุ่นพร้อมกันทุก host และไม่ย้อน bootstrap/custom rules ในโครงการโดยอัตโนมัติ
