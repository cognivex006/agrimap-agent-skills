# Evidence-driven analysis

Separate observed facts (with source), inference, hypotheses and unknowns; inspect the target and affected callers enough to support the conclusion. Follow [recommendations.md](recommendations.md).
Database conclusions require actual caller and object/schema evidence: local context first, then the read-only managed route in db-schema-context.md. Analysis never authorizes data writes.
Answer at the requested depth; persist an analysis document only when requested or needed downstream.
