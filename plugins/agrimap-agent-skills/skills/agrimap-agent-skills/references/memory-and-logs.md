# Useful state and audit

All project state is under <project>/.agrimap-agent, never the global installation. Ordinary conversation has no lifecycle. Capture relevant raw submissions once at prompts/YYYY-MM/<conversation>/history.md; AI text never belongs there. It is local only (Git-ignored): never commit it.

Bounded durable work records concise milestone logs and current/recent memory. The current memory file is the savepoint (5.0.1): goal, done, remaining, next step, decisions, branch. Update it with `checkpoint --done/--remaining/--next` or `savepoint` at milestones and before pausing; `pending` lists unfinished work, `resume --execution <id> --session <id>` moves it here. No new tasks/; reports and separate analysis/QA/results only when requested.
Current memory is working state, recent is a concise outcome journal, project.md holds `## Facts` and release checkpoints only (completed work lives in history and recent memory). Logs are one file per execution: logs/YYYY-MM/YYYY-MM-DD/<id>.jsonl; older daily files stay readable. policy/ is committed team state; cache/ is derived. local/memory.md is this machine's memory (external spec paths), Git-ignored; runtime/ is script state. Committed files never contain absolute machine paths. Reopen relevant state after compaction/resume, validate against current files, and do not load unrelated history.
Completion copies the done list into recent memory and removes the savepoint; blocked or paused work keeps it. Tracked runs started before 5.0.1 still archive tasks to tasks/complete. Never migrate/delete historical artifacts automatically. Legacy schema v1-v4 audit remains readable; requester, executor, file claims and Git authorship are distinct.
Runtime generates timestamps/IDs/metadata. Confirmed requester attribution persists in the user/workspace scope; it is not owner authority. Record actual model separately from modelLabel.
Use one lifecycle owner: installed runtime or portable fallback emits the same evidence, not two parallel runs.
